# baseline 고정 — OB_MODE=engulf + DISP_ATR_MULT=1.3 (+ refine ON)

> 18런 게이트 스윕 + 연도별 walk-forward 결과, **engulf + displacement ATR 1.3** 을
> 새 baseline 으로 고정한다(`config.py` 기본값 변경). env 로 옛값 override 가능.

---

## 1. 변경된 config 기본값

| 상수 | 옛 기본값 | 새 기본값 | 비고 |
|------|----------|----------|------|
| `OB_MODE` | `strict` | **`engulf`** | 18런서 engulf×atr13 최강 |
| `DISP_ATR_MULT` | `0.90` | **`1.3`** | 유일한 일관 unlock 축 |
| `USE_H1_REFINE` | `0`(off) | **`1`(on)** | 인과 + 확인됨 |
| 나머지(`SWEEP_RECENT_N=10`, `DISP_BODY_RATIO=0.45`, `MSS_MODE=legacy`) | — | 현행 유지 | 기각/보류 |

> ⚠️ **의도된 동작 변경**(baseline 자체가 바뀜) → 골든 바이트동일 대상 아님.
> env 로 옛값(`OB_MODE=strict DISP_ATR_MULT=0.9 USE_H1_REFINE=0`)을 주면 이전 결과 재현.

## 2. 회귀 확인 (✅)
- **새 기본값(env 없음)** = `engulf_atr13` 런과 **트레이드 차이 0** (완벽 재현).
- **옛값 env** = 이전 strict baseline 과 **1트레이드만 차이**(= 알려진 BNBUSDT 2023-08-01 선재 비결정성, 회귀 아님).

## 3. Walk-Forward 연도분석 (⭐ 채택 근거 강화)

고정 파라미터(재최적화 없음)로 `engulf_atr13` trades 를 entry 연도별 분할, 실현기준.

| 연도 | atr13 PF | base PF | atr13 avgR | base avgR | atr13 +코인 | atr13 나머지6 PF |
|------|---------:|--------:|-----------:|----------:|:----------:|----------------:|
| **ALL** | **1.146** | 0.944 | +0.115 | −0.001 | 7/9 | 1.151 |
| 2023 | **1.781** | 1.099 | +0.243 | +0.026 | 7/9 | 2.396 |
| 2024 | **1.274** | 1.021 | +0.129 | +0.035 | 8/9 | 1.356 |
| 2025 | **1.242** | 0.910 | +0.116 | −0.025 | 6/9 | 1.440 |
| 2026(부분) | 0.984 | 0.888 | −0.019 | −0.049 | 3/9 | 0.821 |

**판정**:
- ✅ **atr13 이 매 연도 base 를 이김**(PF·avgR 모두, ALL/2023/2024/2025/2026 전부).
- ✅ 통과기준(4창 중 3+ 에서 PF>1 & base 대비 +) **충족**: 2023·2024·2025 모두 PF>1, base 손실연도 2025(0.910)를 **1.242 로 끌어올림**.
- ⚠️ **2026 은 부분연도(251건, ~반년)** 라 atr13·base 둘 다 약함(CI 0 가로지름). 레짐 의존이라기보단 표본부족/최근구간. atr13 이 그래도 base 보다 나음.

> 도구: `python tools/walkforward_year.py` (기존 trades.csv 분석, 새 백테스트 불필요).
