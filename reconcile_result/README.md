## MDD 해부 (독립검증 완료)
손실 채널은 설계상 **① 존터치→TP1 못가고 −1R(풀스탑) 단 하나**. TP1/BE가 꼬리 차단해 ②~⑤ 폭발 불가.
MDD 윈도우(2023-03)는 풀스탑률 43→51% + 승자(③④⑤) 32→20% 기근이 겹친 촙장세. 고risk 풀스탑이 손실 증폭(21%가 40%).
→ TP구조 무결. MDD 레버 = 캡·(향후)동시총risk캡, SL·트레일 조정 아님.
