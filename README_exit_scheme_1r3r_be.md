# 청산 스킴 분석: 1R3R 트레일 + BE 변형 (2026-07-22)

v3/v4 진입셋에 대한 청산 스킴 완전체 백테. **진입 재생성(run_walkforward) + 1m 정직청산(entry+4h)** 기준.

## 1. v3 고정TP 진입봉 누수 발견·정직화 (선행)

`v3_replay_exits.py`가 청산 walk를 진입시각봉(j0)부터 시작 → 진입 H4봉 4시간의 체결전 움직임까지 TP로 카운트하는 look-ahead. v4 H4 sim(`simulation.py:188 range(entry_idx+1,...)`)은 진입봉 스킵(정직). 정직화(entry+4h) 결과:
- 거래: PF 2.33→1.80, 합R 682→461(−32%), 108건(9.6%) 공짜무빙 승리 소멸
- 포트폴리오 v3(1%): CAGR 366→**178.6%**, 월승률 96→82%, 최종 $7.4M→$813K

## 2. 청산 스킴 완전체 백테 (1R3R vs 네이티브 v4)

`run_1r3r_fullbt.py` — 진입 재생성 + 1R3R 트레일(활성3R·폭1R) 1m청산. run_walkforward 자본모델(5M KRW).

| 지표 | 1R3R 트레일 | 네이티브 v4(부분익절+러너트레일) |
|---|--:|--:|
| PF | **2.18** | 1.64 |
| OOS PF | **2.32** | 1.42 |
| expR | **0.643** | 0.257 |
| 자본 CAGR | **329%** | 82% |
| 자본 MDD | −15.2% | −11.1% |
| WF PF≥1 | 100% | 100% |

**왜 1R3R이 이기나**: MFE 두꺼운 꼬리(평균 6R, 18%가 ≥10R). 네이티브 v4는 1/2/3R서 60% 스케일아웃 → 러너 죽임. 1R3R은 풀포지션 유지 → 꼬리 수확. MFE≥3R 구간에서 1R3R +381R 우세, MFE<3R에서 v4 +129R 우세, 순 +252R.

## 3. BE 변형 랭킹 (최종금액순, 동일진입·자본시뮬)

| 스킴 | 최종KRW | CAGR | MDD | PF |
|---|--:|--:|--:|--:|
| 1R3R+BE@2R | 113.8억 | 337.9% | −14.4% | 2.32 |
| 순정 1R3R | 104.2억 | 329.2% | −15.2% | 2.18 |

- **BE는 수익 못 늘림(러너 살해) — 리스크(MDD·PF) 개선 보험**. BE@2R 최대금액(파레토), BE@1R 최고 PF/리스크, BE@1.5R 최고 일관성(손실월 5/53).
- 전체기간 랭킹은 BE@2R 우위, **2026만 보면 BE@1.5R 1위**(레짐 의존).
